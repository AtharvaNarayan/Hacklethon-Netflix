# Netflix Clone with Enhanced Features

A modern Netflix clone built with React, featuring several innovative additions to the traditional streaming experience.

## Features

### 🎬 Watch Together
- Real-time video synchronization
- Live chat with room members
- Emoji reactions during playback
- Theater mode for optimal viewing
- WebSocket-based synchronization
- Room creation and management

### 🛍️ Shopping Section
- Purchase movies in various formats
- Shopping cart functionality
- Stock availability tracking
- Easy checkout process
- Multiple format options

### 👀 Preview on Hover
- 3-second video previews
- Themed preview clips
- Smooth transitions
- High-quality snippets
- Auto-looping previews

## Technologies Used

- React.js
- Framer Motion for animations
- TailwindCSS for styling
- WebSocket for real-time features
- Modern UI/UX principles

## Getting Started

1. Clone the repository
```bash
git clone [repository-url]
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser
